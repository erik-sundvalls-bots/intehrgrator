      Default context map is the unique canvas table you author here. At convert time, generated Conversion Scripts receive it as a defaults argument keyed by runtime key (language, facility, …). maps_get("defaults", runtimeKey) looks those up. Runtime code can merge that bag with per-message values, other named maps, and Sheet grids — the canvas map is the reusable baseline, not literals baked into every slot.
    
      Scaffold targets (chips) are authoring-only RM paths, not convert-time keys: Class.attribute (e.g. COMPOSITION.composer, EVENT_CONTEXT.health_care_facility), ancestor paths, and wildcards (*.language lights every language slot). A more specific chip wins when several match the same slot. Empty chips → a runtime-only key that lights nothing. Extra keys stay available for Map lookups even if they do not light a slot.
    
      Confirm, Apply default context map, or a later target refresh join Default points. Value edits are live in Test Run. A slot already mapped from source is not replaced.
    
      The folder opens load/save: pick a map saved in this browser, browse a JSON file, load a URL, save a named copy, or download the current map as JSON you can upload again later.
        
      
  
    
    
      Decision table is a named rule grid in the Tables & Sheets tab: condition columns (equality, don't-care —) and output columns (plain values or VMS-Mustache snippets). The grid owns column names and types; this block’s locals Map keys stay in sync.
    
      Plug a Map of locals on the right (keys = condition headers). The output dropdown returns one typed column (🔤 string, 🔢 number, ✓ boolean), or all outputs as a Map (↦). Switching that type may unplug the block; canvas undo/redo restores it.
    
      Hit policy (FIRST / UNIQUE / COLLECT) is on the Tables & Sheets tab. Flatten nested sources into the locals Map (or via variables) before eval.
